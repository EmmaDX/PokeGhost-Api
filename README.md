Esta es una API que contiene diferentes endpoints de tipo GET, asi como algunos de tipo POST, PUT y DELETE.
La API tiene la tematica de pokemones de tipo fantasma conteniendo su informacion como, numero de pokedex, nombre, clasificacion primer y segundo tipo en caso de tenerlo y su imagen sacada de Wikidex.net
La finalidad de esta API fue entender el funcionamiento de las mismas creandola con un tema sencillo de entender
